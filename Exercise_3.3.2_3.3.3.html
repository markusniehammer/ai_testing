Schritt 4: Metriken berechnen

Die Werte werden aus True Positives, False Positives, True Negatives und False Negatives berechnet. Bei mehreren Klassen nutzt die Übung eine Macro-Average-Betrachtung: Die Metrik wird pro Klasse berechnet und anschließend gemittelt.
